# CIS-165 Lab 4: Averages and Ocean-Level Projections

## Program Plans

### Program 1 — Average of Five Values (`average.cpp`)
1. Create five separate `double` variables containing 28, 32, 37, 24, and 33.
2. Add the five variables and store the total in a variable named `sum`.
3. Divide `sum` by 5 and store the result in `average`.
4. Display the sum and average with clear labels.

### Program 2 — Ocean-Level Projections (`ocean_levels.cpp`)
1. Create a named constant for the annual ocean-level rise of 1.5 millimeters.
2. Create separate variables or named constants for 5, 7, and 10 years.
3. Multiply the annual rate by each year value and store each result in a separate variable.
4. Display the three projected increases with clear labels and millimeter units.
